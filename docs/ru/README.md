# Русская документация DiffMosaic

Этот раздел помогает читать и демонстрировать проект без необходимости сначала
разбираться во всём исходном коде.

| Документ | Для чего нужен |
| --- | --- |
| [Руководство разработчика](guide-developer.md) | Запустить анализ PR, прочитать отчёт и безопасно использовать мутации. |
| [Научный протокол](research-protocol.md) | Понять гипотезу, единицу наблюдения, метрики, результаты и ограничения. |
| [Демонстрация преподавателю](presentation-guide.md) | За 7–10 минут показать проблему, работу инструмента и честные выводы. |
| [Черновик статьи](../../paper/diffmosaic-article-ru.md) | Основа для статьи, доклада или студенческой конференции. |

Английские первичные документы находятся уровнем выше в [`docs/..`](..):
архитектура, протокол контейнерного исполнения, правила ранжирования и журнал
решений. При расхождении между кратким русским описанием и машиночитаемыми
артефактами приоритет имеют исходный код, `corpus/pilot-v0.1.json` и сохранённые
отчёты экспериментов.
